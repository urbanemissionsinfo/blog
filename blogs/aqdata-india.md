# Where can I download AQ data for Indian Cities

The first place to look for is [CPCB portal](https://airquality.cpcb.gov.in/ccr/#/caaqm-dashboard-all)
You can download the archives, by year and by station, follow the tabs on top.

There is [official AQI](https://airquality.cpcb.gov.in/ccr/#/all-india-aqi-portal), issued in real-time

There is an official AQI bulletin (PDF), issued every day at 4pm. This is a sample bulletin: [AQI Bulletin Sept 17, 2026](https://cpcb.gov.in//upload/Downloads/AQI_Bulletin_20260917.pdf)
We archived data from these PDFs here: [AQI Bulletins, Urban Emissions Info](https://urbanemissionsinfo.github.io/AQI_bulletins/)

## Here are independent/private/current/archive portals

1. A github repository of from 2006 to part 2019: [pradushan/cpcb](https://github.com/pradushan/cpcb)
2. [OpenAQ](https://openaq.org) -- archives, real time 
3. [Rainmatter/Aurrasure](https://oaq.notf.in/) -- archives, real-time
4. [EnviroCatalysts](https://www.envirocatalysts.com/airquality-dashboard) -- archives, real-time
5. [Earthmetry](https://www.earthmetry.com) -- archives
6. [XKDR](https://www.xkdr.org/system/india-air-quality-database) -- archives
7. [Daily AQ bulletin](https://ncap.energyandcleanair.org/) by CREA
